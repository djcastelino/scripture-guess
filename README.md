# 📖 ScriptureGuess - Daily Bible Character Challenge

Guess the Bible character from 6 progressive clues. A new puzzle every day!

## Features

- 📖 **50 Bible Characters** - Old and New Testament
- 🎯 **Progressive Clues** - Get more hints with each guess
- 📱 **PWA** - Install on your phone like a native app
- 🔥 **Streak Tracking** - Track your daily streak
- 📤 **Share Results** - Share your score with friends
- 💾 **Offline Support** - Play even without internet

## How to Play

1. Read the first clue about a mystery Bible character
2. Type your guess in the search box (autocomplete helps!)
3. Wrong guess? Get more clues revealed!
4. You have 6 guesses to find the answer
5. Come back tomorrow for a new puzzle!

## Tech Stack

- React 18 + TypeScript
- Vite
- PWA (Progressive Web App)
- LocalStorage for game state
- No backend required!

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

Deployed on Vercel with automatic deployments from main branch.
